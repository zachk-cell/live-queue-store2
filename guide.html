1 What it is

The Poke Pig Live Queue is the running order-of-service board for your TikTok Shop lives. It pulls paid orders straight from the TikTok Shop Order API while you're live, groups and prioritizes them by your rules, and shows a self-updating feed on three surfaces at once.

Three surfaces

  • Admin panel — where you pack from. Full detail, all controls.
  • Public page — what buyers watch. Position, username and a PRIORITY tag only; no totals or personal info.
  • Discord — an auto-updating mirror of the queue plus the Piggy Bank tally, with a few mod commands.

The core ideas

  • No typing. Orders ingest automatically from TikTok while you're live.
  • One slot per buyer. A buyer who orders again before you fulfill them merges into their existing slot instead of getting re-queued.
  • Item-driven priority. An order containing a configured priority item jumps that buyer to the top.
  • Session-based. Nothing ingests until you hit ● Go Live.
TimezoneEverything time-stamped in this queue is in Mountain time (MST/MDT). Where you type a time (Stream Clips), you type your own local clock and the app records and displays it in Mountain for you.

2 Getting in

  1. The operator guide & sandbox (this page and /sandbox) sit behind a shared guide password. Anyone helping out can be given that without handing over the admin login.
  2. The admin panel lives at a secret, unlinked URL and is protected by its own password. If two-factor is switched on, you'll also enter a 6-digit code from your authenticator (or a one-time backup code).
  3. Once you're in the panel, your login lasts about 30 days on that device, so you normally sign in once and stay in.
TipPractice everything in this guide risk-free on the interactive sandbox — it's a full copy of the board with make-believe orders. Nothing there is real; refresh to start over.

3 Going live

The board does nothing until you start a session. When you're ready to sell, hit ● Go Live at the top left of the panel and confirm.

What Go Live does, in order

  • Archives anything left over from a previous stream that wasn't properly ended (so nothing is lost), then clears the board for a fresh session.
  • Starts accepting orders. From this moment TikTok orders flow in automatically (polled every few seconds).
  • Auto-starts the Stream Clips timer at that exact moment and begins a fresh clip log for this stream. You can still fine-tune the start time by hand later.
  • Runs a pre-live backfill. It quietly pulls in any orders placed in roughly the 15 minutes before you went live, so a late start doesn't miss early buyers. This runs in the background — going live stays instant, and the orders stream in as they're fetched.
Why the backfill mattersPeople start buying the second you go on. If you were a few minutes late hitting Go Live, those orders still land in the queue. The backfill is idempotent — it only adds orders that aren't already there and are still unshipped, so it can never create duplicates.
Heads upWhile you're offline (before Go Live / after End Live) incoming orders are ignored, not queued. Only orders placed during a live session — plus that 15-minute pre-live window — enter the board.

5 Flags & badges — and what to do

Badges sit on the buyer's name row. Here's every one and the action it's asking for:

BadgeMeansDo this
PRIORITY The slot contains a configured priority item, so it jumped to the top tier. Pack it ahead of normal slots. Multiple priority buyers stack at the top by who bought first.
N orders This buyer has N separate orders merged into one slot (items and total combined). Pack them together as one bag. Expand the row to see each order broken out.
＋ ADDED MORE ×N This buyer ordered again while already at #1 — their bag is probably being packed right now. The ×N is how many times they've added since reaching the top. Add the new item(s) to the bag in progress. Don't seal it assuming the slot was done. Only flashes while they are currently #1.
🔁 N earlier today This buyer already had order(s) fulfilled earlier this same stream. Decide whether this should be combined into one shipment with what you already packed.
⚠ SAME NAME id …a2f1 A different buyer in the queue has the exact same display name. These are different people (the queue tells them apart by buyer id, not name). Use the id …last4 tag and the order numbers to keep the two straight. Don't merge them.
⚠ CANCEL REQ A genuine cancellation was requested — the whole order, or a specific item. Expand the row to see exactly which item is flagged (it's highlighted). Do not ship or seal until the cancelled item is pulled.
⏸ ON HOLD — verify TikTok put the order On Hold for some other reason — address check, order combine/split, a sample/exchange, or a pending review. This is not a cancellation. Just verify before shipping. (Suppressed automatically if a real CANCEL REQ is already flagged.)

6 The fulfill loop

Working the board is a simple rhythm — always start from the top:

  1. Look at row 1. Read its badges (priority, added-more, cancel, same-name).
  2. Expand it if you need the full item list (see expanded view), print a 🏷 Label if you use them.
  3. Pack the bag. If it's a multi-order slot, everything in that slot goes together.
  4. Hit ✓ Fulfilled. That closes the whole buyer batch and moves it to Fulfilled this stream.
  5. The next slot slides up to #1. Repeat.
Slot merging, in practiceIf a buyer you already fulfilled orders again later, a fresh slot opens for them. If they order again before you fulfill them, it merges into the same slot — that's the N orders badge, and, if they were already at the top, the ＋ ADDED MORE flash.

7 Action buttons

On each slot

  • ✓ Fulfilled — closes the whole buyer batch and files it under Fulfilled.
  • ▲ Bump — force this slot to the very top. Only one slot can be bumped at a time; bumping a new one releases the last.
  • ✕ Remove — take the slot off the board without fulfilling it (e.g. the buyer cancelled). It moves to Cancelled this stream.
  • ▸ Expand — show/hide every item in the slot.
  • 🏷 Label — print a 2.25×1.25 shipping label with the username and order numbers.

Up top / in sections

  • ● Go Live / ■ End Live — start or stop the session.
  • ⭐ Priority items — edit the list of phrases that trigger priority (one per line, matched inside the item name).
  • Reset — clear the active board. Use with care.
  • ↩ Undo / Restore — on any Fulfilled or Cancelled row, put the slot back on the board (only if that buyer has no newer open slot).
  • ⬇ Export CSV — download the stream's orders (see wrapping up).

9 The Piggy Bank 🐷

The Piggy Bank is Poke Pig's per-variant sales counter. Each tracked variant gets a running unit total that persists across streams — it keeps climbing live after live until you reset it (for example when the bank is "hit").

How it counts

  • Units are tallied automatically when a slot containing a tracked variant reaches the top of the queue.
  • Matching is on the item text — a variant needs its variant phrase (and its product phrase, if one is set) to appear in the item name.
  • The counts are cumulative running totals, so they're not cleared by Go Live or End Live.

Adjusting a counter

  • You can manually set or reset any counter from the admin panel.
  • Every manual change is written to an audit log with the previous value, so a mistaken edit or reset is always recoverable.
Where it showsThe Piggy Bank tally appears on the admin panel, on the public page (label + count only), and as its own pinned Piggy Bank Tracker message in Discord.

10 Stream Clips

Stream Clips is a timestamp tool for your video editor. During the stream you flag moments worth clipping with one tap, and the app hands the editor a clean, copyable list.

The timer

  • The clip timer auto-starts the moment you hit Go Live, and a fresh clip log begins for that stream.
  • When you hit End Live the running timer freezes — but the start time and every clip are kept, so the list stays copyable for the editor afterward.
  • You only need 🕐 Set start time if you want to correct the auto-set start.

Times are typed local, recorded Mountain

ImportantYou type the start time and each clip time in your own local clock — whatever time you're looking at. The app records and displays it in Mountain (MT) for the editor. Elapsed times are the same in any timezone, so they always line up with the recording.

Marking & editing clips

  • Hit ✂ Time Clip to drop a clip at the current moment (the button unlocks once a start time is set).
  • Each clip row is fully editable: its clock time (type in your local time), its elapsed value (h:mm:ss since stream start), and a free-text note. Editing one keeps the other in sync.
  • Use ⧉ Copy list to grab the whole list for the editor, or Clear all to wipe it.

11 Paging & search

Page size

On a big live the active queue can get long. The Show N per page dropdown (10 / 25 / 50 / 100) controls how many slots render at once, with pager controls below. Your choice is remembered on that device.

Order-# search

The search box filters by buyer name or order number — full number or just the last few digits. Handy when a buyer reads out their order number in chat and you need to find their slot fast.

12 Discord & mod commands

When Discord is enabled, the bot keeps a single auto-updating live queue message in the channel (position, username and a ⭐/🔺 marker only — no totals or personal info, matching the public page), plus a separate pinned Piggy Bank Tracker message.

Mod commands

  • /queue — refresh / re-show the live queue message.
  • /fulfill [buyer] — mark the top slot (or a named buyer) fulfilled without opening the web app.
  • /bump <buyer> — bump a named buyer to the top.
NoteThe web dashboard is always the primary control surface — Discord mirrors it so mods and buyers can follow along and mods can help from their phone.

13 Wrapping up — End Live

When the stream is over, hit ■ End Live and confirm. This:

  • Archives the entire stream — fulfilled, cancelled, and anything still unfulfilled — to Past streams, so nothing is silently lost.
  • Clears the board and stops new orders from entering.
  • Freezes the Stream Clips timer (start time and clips are kept and stay copyable).

Afterward you can review or export any past stream:

  • 🗂 Past streams ↗ keeps the last handful of streams with their counts and value.
  • ⬇ Export CSV downloads a spreadsheet — a summary by buyer, every fulfilled order, plus the cancelled and any unfulfilled orders — for shipping and reconciliation.
Don't forgetAlways End Live when you're done. If you leave a session open, the next Go Live will archive the leftovers for you — but ending cleanly keeps your Past streams and averages accurate.

14 Golden rules

1
Always pack from the top down. Row 1 is always the next bag. Trust the sort.
2
Go Live before you sell, End Live when you're done. Offline = orders are ignored.
3
Red ⚠ CANCEL REQ = stop. Expand, pull the flagged item, and never seal until it's handled.
4
Green ＋ ADDED MORE = add to the bag in progress. The buyer bought again while at #1.
5
Same name ≠ same person. Use the id …last4 tag and order numbers to tell them apart.
6
Type clip times in your local clock. The app records them in Mountain for the editor.
7
The Piggy Bank persists. Don't reset a counter unless the bank is actually hit.

15 Quick fixes

Orders aren't coming in. Check the LIVE badge — if it says OFFLINE, hit Go Live. If it's live, check the green Live feed dot; a dropped feed reconnects on its own, and refreshing the page pulls the latest state.
I started the queue late and missed early orders. The pre-live backfill already grabs the last ~15 minutes automatically on Go Live. It's idempotent, so it never duplicates what's there.
I fulfilled the wrong slot. Open Fulfilled this stream and hit ↩ Undo on that row — it returns to the board (as long as the buyer has no newer open slot).
A buyer added more after I started their bag. Look for the ＋ ADDED MORE flash on #1 and expand the row — the new items sit under Added since top of queue.
Two buyers have the same name. That's the ⚠ SAME NAME flag. Match on the id …last4 tag and the order number, not the name.
The Time Clip button is greyed out. Set a stream start time first (it's normally auto-set at Go Live) — the button unlocks once a start exists.
A Piggy Bank number looks wrong. You can set or reset it manually in the panel; every change is logged with the old value, so nothing is lost.
Still stuck?Nothing you click can lose data — the board is saved continuously and every ingest is idempotent, so refreshing is always safe. Practice the whole flow on the sandbox whenever you like.
